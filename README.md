# GOBLIN STANDARD LIBRARY

Reusable C Utilities and Data Structures

- _gVector_ -> Dynamic arrays, capacity management, resizing, generic data storage. - []
- _gString_ -> Dynamically allocated strings, concatenation, resizing, ownership. - []
- _gMap_ -> Hashmaps, hashing functions, collision handling, key-value pairs. - []
- _gPtr_ -> Smart-pointer like utilities, reference counting. - []
- _gAlloc /gArena_ -> Arena allocators, memory pools, allocations strategies - []

Potential later additions: linked lists, stacks, queues, JSON Parser.
